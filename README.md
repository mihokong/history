# 🦜 모찌와 함께하는 뒹굴뒹굴 세계사

중학교 2학년 역사(세계사) 교과서 성취기준에 맞추어, 학생들이 암기하기 어려워하는 역사 개념을 귀여운 앵무새 **모찌(Mochi)**와 함께 게임식으로 정복할 수 있게 돕는 반응형 정적 웹 사이트입니다.

👉 **배포 주소**: [https://mihokong.github.io/history/](https://mihokong.github.io/history/)

---

## 🏛️ 학습 플랫폼 구조

본 프로젝트는 상단의 대단원 선택 메뉴를 통해 원하는 시대로 넘어가며 개별적인 진행률과 게임화된 퀴즈를 학습합니다.

```
모찌의 뒹굴뒹굴 세계사
├── 🌿 단원 1: 선사 시대의 모험
│   ├── 1-1 인류의 출현 (진화 짝맞추기 카드 게임)
│   ├── 1-2 구석기 vs 신석기 (유물 분류 바구니 게임)
│   ├── 1-3 청동기와 문명 (청동기/문명 OX 낚시 퀴즈)
│   └── 🏁 종합 퀴즈 게임 (상장 수여 및 실물 인쇄 지원)
└── 🏺 단원 2: 고대 서아시아·지중해 세계의 형성
    ├── 2-1 페르시아 제국 (다리우스 1세의 왕의 길 건설)
    ├── 2-2 그리스 & 헬레니즘 (아테네/스파르타/헬레니즘 분류 게임)
    ├── 2-3 로마 제국 (로마 지중해 제국 OX 퀴즈)
    └── 🏁 종합 퀴즈 게임 (지중해 마스터 상장 수여 및 인쇄 지원)
```

## ✨ 핵심 기능 및 디자인 포인트

1. **앵무새 '모찌'의 친근한 역사 과외**
   * 학습 멘토인 모찌가 대화하듯 편하게 설명해주며, 오스트랄로피테쿠스(다리가 **아파렌시스**), 호모 에렉투스(허리를 **에렉!** 세우고 불을 씀), 옥타비아누스(**아우구스투스**-아우 구수해!) 등 외우기 힘들어하는 학생을 위한 **모찌표 꿀팁 암기법**을 카드를 통해 한눈에 볼 수 있습니다.
2. **독립적인 진행률과 비행 애니메이션**
   * 각 단원의 카드 뒤집기, 소제목 오픈, 미니게임을 달성할 때마다 진척도(0% ~ 100%)가 오르고 앵무새 모찌가 둥지를 향해 날아가는 비행 진행바(Flight Progress Bar)가 탑재되어 성취감을 높입니다.
3. **학습 맞춤형 미니 게임 6종**
   * 짝 맞추기, 바구니 드래그 정렬, OX 판독 등 다양한 형태의 웹게임으로 지루할 틈 없이 단어를 마스터할 수 있습니다.
4. **마스터 인증서 발급 & 프린트 기능**
   * 종합 퀴즈 100점(혹은 우수한 성적)을 달성하면 발급되는 역사 마스터 상장을 실물 프린터로 바로 인쇄하거나 PDF로 저장할 수 있도록 프린트용 미디어 쿼리가 내장되어 있습니다.
5. **낮과 밤(Day/Night) 테마 지원**
   * 우측 상단의 태양/달 아이콘 클릭 시 야간 모드로 전환되어 어두운 방에서도 모찌가 잠을 자는 테마와 함께 편안히 공부할 수 있습니다.

## 🛠️ 사용 기술 및 로컬 실행 방법

* **개발 환경**: HTML5, CSS3 (Vanilla), JavaScript (ES6)
* **배포**: GitHub Pages (정적 호스팅)

### 💻 로컬에서 미리 실행해보기
별도의 빌드 도구가 없으므로, 로컬 웹 서버를 가볍게 열어서 실행할 수 있습니다.

```bash
# 1. 저장소 클론
git clone https://github.com/mihokong/history.git
cd history

# 2. 파이썬 기본 정적 웹 서버 구동
python3 -m http.server 8000
```
웹 서버가 구동되면 웹 브라우저 주소창에 `http://localhost:8000`을 입력하여 접속합니다.

## 🚀 GitHub Pages 배포 설정
이 레포지토리의 코드 변경사항이 푸시되면 GitHub Actions를 통해 즉시 정적 웹사이트로 배포됩니다.
1. GitHub 저장소의 **Settings** -> **Pages** 메뉴로 이동합니다.
2. Build and deployment에서 Source를 **Deploy from a branch**로 설정합니다.
3. Branch를 **`main`** 브랜치, 폴더를 `/ (root)`로 지정 후 **Save**를 클릭합니다.
